## 4. Invariant Rules & Data Principles

1. **Master Coordinate Reference System (CRS)**: All spatial distance measurements, curvature evaluations, and grade calculations **must** strictly use **NAD83 / UTM Zone 18N (`EPSG:26918`)**. Unprojected `EPSG:4326` is reserved exclusively for raw data ingestion and GeoJSON visualization.
2. **Read-Only Raw Data**: All files under `data/raw/` are strictly immutable. Processed marts reside in `data/processed/` as compressed Apache Parquet.
3. **Reproducibility & Testing**: Every algorithmic stage is verified with synthetic clean-room unit tests (`tests/unit/`) and accompanied by a domain visual artifact saved to `outputs/figures/phase{N}/`.
